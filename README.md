# ROCA — Spec-Driven Development

Repositorio oficial de especificaciones de ROCA.

Este repositorio contiene la fuente de verdad del diseño funcional, dominio, arquitectura, decisiones y requisitos de ROCA antes y durante su implementación.

## Principio de trabajo

**Conversación → decisión → especificación → validación → implementación → pruebas → aprendizaje → actualización de la especificación.**

La documentación puede estar incompleta. Lo importante es hacer explícito qué está decidido, qué está pendiente y qué contradicciones deben resolverse antes de implementar.

## Estructura inicial

- `docs/sdd/00-product.md` — producto, problema, visión y alcance.
- `docs/sdd/01-principles.md` — principios y reglas de diseño.
- `docs/sdd/02-domain-model.md` — modelo conceptual del dominio.
- `docs/sdd/decisions/` — decisiones relevantes.
- `docs/sdd/requirements/` — requisitos funcionales y no funcionales.
